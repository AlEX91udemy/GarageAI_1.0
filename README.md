# GarageHub — Дневник авто и ремонта

Мультиавтомобильный дневник техобслуживания и ремонта с AI-диагностикой.

## Запуск проекта

**Требования:** Node.js (v18+)

1.  Установите зависимости:
    ```bash
    npm install
    ```
2.  Настройте переменные окружения в `.env`:
    *   `GEMINI_API_KEY` — ключ API Google Gemini.
    *   `GEMINI_MODEL` — (опционально) модель по умолчанию.
    *   `GARAGE_DB_FILE` — (опционально) путь к изолированному JSON-хранилищу.

При первом запуске приложение открывает регистрацию аккаунта. Каждый аккаунт получает
свою сессию в HttpOnly cookie и отдельный гараж. Все операции с автомобилями, ТО,
складом и бэкапами требуют активной сессии; данные разных аккаунтов не смешиваются.
Старый `data/garage_store.json` сохраняется как архив демо-данных и автоматически не
привязывается к новому пользователю.
3.  Запустите сервер разработки:
    ```bash
    npm run dev
    ```
