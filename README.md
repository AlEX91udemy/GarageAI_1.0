## Запуск проекта

**Требования:** Node.js (v18+)

1.  Установите зависимости:
    ```bash
    npm install
    ```
2.  Настройте переменные окружения в `.env`:
    *   `GEMINI_API_KEY` — ключ API Google Gemini.
    *   `GEMINI_MODEL` — (опционально) модель по умолчанию.
    *   `GARAGE_DB_FILE` — (опционально) путь к изолированному JSON-хранилищу.

При первом запуске приложение открывает гараж в гостевом режиме без обязательного входа. Данные сохраняются локально; авторизация доступна из профиля для синхронизации с сервером. После входа каждый аккаунт получает свою сессию в HttpOnly cookie и отдельный гараж, данные разных аккаунтов не смешиваются. Старый data/garage_store.json сохраняется как архив демо-данных и автоматически не привязывается к новому пользователю.
3.  Запустите сервер разработки:
    ```bash
    npm run dev
    ```
