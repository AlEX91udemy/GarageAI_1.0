# Garage AI: цветовая палитра

Версия: **1.0.0**  
Дата: **21.10.2026**  
Источник истины для машинного использования: [`color-palette.json`](./color-palette.json)

## Идея

Garage AI выглядит как инструмент для водителя, а не как развлекательное приложение:

- глубокий сине-графитовый фон;
- два системных красных: брендовый `#EF3038` и основной action `#B91C1C`;
- холодные нейтральные поверхности;
- зелёный, янтарный и синий только для статусов;
- фиолетовый, циан и розовый только для графиков и категорий.

Лайм, оранжевый и «почти красные» оттенки в ядро палитры не входят. Они создают ощущение другого продукта и должны считаться legacy.

## Правила

1. Красный является единственным брендовым акцентом. Не добавляйте лайм, оранжевый, фиолетовый, циан или розовый в основные элементы интерфейса.
2. Основная кнопка: фон `#B91C1C`, hover `#991B1B`, текст `#FFFFFF`. Не ставьте белый текст на `#EF3038`: контраст 4.08:1 ниже AA для обычного текста.
3. Активная навигация на светлом: `#B91C1C`. На тёмном: `#EF3038` для иконок и крупных элементов, `#F87171` для обычного текста.
4. `#EF3038` на карточке `#17202E` даёт 4.02:1: этого достаточно для иконок и крупного текста, но не для мелкого. Для мелкого текста используйте `#F87171`.
5. В тёмной теме одна канва (`#0D131D`), одна карточка (`#17202E`), один elevated-слой (`#1E293B`) и одна основная граница (`#243044`).
6. В светлой теме одна канва (`#F4F5F8`), одна карточка (`#FFFFFF`), один вложенный фон (`#F8FAFC`) и одна граница (`#E2E8F0`).
7. Окраска автомобилей, цвета 3D-моделей и цвета иллюстраций не считаются UI-палитрой.
