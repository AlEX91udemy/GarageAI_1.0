# Garage AI Vehicle Knowledge Graph

Существующий Garage AI использует React/Vite frontend, Express backend и атомарное JSON-хранилище `data/garage_store.json`. Пользовательский автомобиль остаётся совместимым с плоским типом `Vehicle`; нормализованный каталог размещён в `src/catalog` и строится из существующего `src/carCatalog.ts` без дубликатов визуальных ассетов.

## Каталог и происхождение

`src/catalog/database.ts` содержит справочники Brand, Model, Generation, Modification, Engine, Transmission, BodyType, Drivetrain и FuelType. Каждая сущность, полученная из текущего каталога, связана с `source-legacy-catalog` и имеет confidence `low`, пока не подтверждена официальным документом. Неизвестные характеристики представлены `null`.

Текущая база legacy-каталога: 19 марок, 55 моделей, 110 поколений. Число модификаций формируется из декартова набора заявленных вариантов поколения; это техническая матрица для выбора и требует дальнейшей верификации по рынку РФ. Она не объявляется рейтингом продаж TOP-100.

## Knowledge base / RAG

`src/catalog/knowledge.ts` хранит небольшие chunks с metadata (категория, автомобильный контекст, source/sourceType/sourceId). `searchKnowledge()` выполняет детерминированный поиск по токенам и фильтрам. Серверный `/api/knowledge/search` отдаёт найденные chunks и provenance; AI-диагностика может использовать этот контекст перед вызовом модели.

Для формирования подтверждённого TOP-100 и технических регламентов нужно отдельно загрузить официальные документы производителей и статистику российского рынка за 2025–2026 годы. До этого значения не считаются подтверждёнными и не подменяются догадками.
