В README задокументированы настройки: корень репозитория, Build command `npm run build`, Deploy command `npx --yes wrangler@4.152.0 deploy`, Worker `garageai-1-0`. Проблемные build ID: `e5d8fa36-f1ab-4147-a1ae-c0845ea26375` (PR #28), `c8f15e64-7655-4368-872d-6918de18a0dc`, `66029486-5232-449d-b23d-04ace778bf88`.
**Следующее действие:** в Cloudflare Dashboard открыть Workers & Pages → garageai-1-0 → Build History → failed build → Build logs и передать первую ошибку с несколькими строками контекста. Не менять конфигурацию наугад. Фиксация npm-версии не решила проблему.

### Google Cloud / Cloud Run
Cloud Build `ef9421f7-cf8e-4d8d-a774-4b32853f7275`: Pull, Build, Push успешны, Deploy завершился ошибкой. В ссылке фигурирует проект `garage-ai-512223`, а в части документации — `garageai-512320`. Сначала сверить фактический проект и trigger, затем проверить лог Deploy, IAM/OIDC и тестовый HTTP-запрос. Production-деплой не подтверждён.

### Email-код — незавершённая работа
Экспериментальная ветка: `feature/email-code-authentication`. В ней подготовлены вспомогательные функции нормализации email/генерации и хеширования кода, тесты этих функций, SQL-заготовка `002_email_auth_challenges.sql` и env placeholders для Resend. Полный flow пока не подключён.
Нужно реализовать/проверить: email в пользовательской схеме, persistence для challenge, request-code и verify-code API, отправку через Resend, expiry, max attempts, rate limits по IP/email, атомарное одноразовое использование кода и интерфейс `AuthGate`. Сохранить текущий вход по username/password. Не логировать код/секреты и не раскрывать наличие аккаунта. Не сливать ветку и не считать email-вход рабочим до полного покрытия тестами и успешного CI.

## Ограничения
- Успешный GitHub Actions или Wrangler dry-run не доказывает production deployment.
- OCR-классификация не доказывает, что запись сохранилась.
- Исторические версии `data/garage_store.json` могут содержать пользовательские данные. Не переписывать Git history без отдельного согласования.
- Каталог ранее содержал 110 записей: 0 verified, 10 partially_verified, 100 provisional. Не повышать статус без подтверждающих источников.
