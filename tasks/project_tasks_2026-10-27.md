## Важные задачи

1. **Cloudflare — блокирует выпуск.** Нужно получить первичную ошибку из Cloudflare Workers Builds. README теперь содержит ожидаемые настройки: корень репозитория, Build command `npm run build`, Deploy command `npx --yes wrangler@4.152.0 deploy`, Worker `garageai-1-0`. Эксперимент с фиксацией npm-версии не помог; не менять конфигурацию наугад без лога.

2. **Авторизация по email-коду — не завершена.** В отдельной экспериментальной ветке есть вспомогательные функции генерации/хеширования кода и SQL-заготовка, но полноценные эндпоинты, отправка письма, ограничения попыток/срока и UI ещё не подключены. Не считать эту авторизацию рабочей и не выкатывать незавершённую ветку.

3. **Сканирование — частично выполнено.** PR #33 объединён: в быстром меню вместо двух верхнеуровневых пунктов теперь одно действие «Сканирование», после которого можно выбрать «Чек / заказ-наряд» или «Деталь / VIN». Сами сценарии сканирования пока остаются разными. PR #32 также исправил вероятный дефект классификации: чеки АЗС, проходящие через Google Document AI, могли получать категорию `other` и не предлагать запись в журнал заправок; добавлена классификация OCR-текста и тесты.
