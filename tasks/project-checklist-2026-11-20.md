## Условия наблюдения

- 5xx ниже 1%.
- Нет P0/P1 инцидентов и нерешенных ошибок Cloud SQL, email или AI.
- API p95 не выше 2 секунд.
- Расход не выше 50 SGD за согласованный период.
- Предыдущая Cloud Run revision сохранена для rollback.
